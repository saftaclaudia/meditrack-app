**MediTrack** is a full-stack web application designed for women 40+ to take control of their health — track recommended medical exams, manage appointments, and monitor daily nutrition for optimal wellbeing.

---

## 🌸 Who Is This For?

MediTrack is built specifically for women over 40, a life stage where preventive healthcare and balanced nutrition become increasingly important. The app provides a centralized, easy-to-use platform to stay on top of recommended medical screenings and daily calorie goals.

---

## 🚀 Features

### 🏥 Medical Exam Tracking

- Add, edit, and remove medical exams with specialty, doctor, and date information.
- Track exam status: **Completed**, **Soon**, or **Upcoming** with visual badges.
- Upload and manage related documents (PDFs, images, etc.).
- Automatic reminders when an appointment is approaching.
- Notifications when a recommended exam is overdue.

### 🥗 Nutrition Tracking _(coming soon)_

- Log daily calorie intake.
- Monitor nutritional goals for a healthy weight.
- Daily reminders to complete your food journal.

### 🔔 Smart Notifications

- Automated notifications generated by background jobs (cron).
- Appointment reminders (7 days before).
- Overdue exam alerts.
- Daily nutrition reminders.

### 🎨 General

- Dark & Light theme toggle.
- Fully responsive for desktop and mobile devices.
- Secure authentication with JWT.

## 📦 Installation

### Prerequisites

- Node.js 18+
- MongoDB (local or Atlas)

### Clone & Install

```bash
git clone https://github.com/saftaclaudia/meditrack-app.git
cd meditrack-app
```

**Backend:**

```bash
cd meditrack-api
npm install
```

**Frontend** (root of the project):

```bash
cd ..
npm install
```

### Environment Variables

Create a `.env` file in the `meditrack-api/` directory:

```env
PORT=5001
MONGO_URI=mongodb://localhost:27017/meditrack
JWT_SECRET=your_jwt_secret_here
```

### Run in Development

**Backend:**

```bash
cd meditrack-api
npm run dev
```

**Frontend** (from project root):

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🔌 API Overview

All protected routes require a `Bearer` token in the `Authorization` header.

| Method | Endpoint                  | Description                      |
| ------ | ------------------------- | -------------------------------- |
| POST   | `/auth/register`          | Register a new user              |
| POST   | `/auth/login`             | Login & receive JWT              |
| GET    | `/exams`                  | Get all exams for logged-in user |
| POST   | `/exams`                  | Add a new exam                   |
| PUT    | `/exams/:id`              | Update an exam                   |
| DELETE | `/exams/:id`              | Delete an exam                   |
| GET    | `/notifications`          | Get all notifications            |
| PATCH  | `/notifications/:id/read` | Mark one as read                 |
| PATCH  | `/notifications/read-all` | Mark all as read                 |
| POST   | `/notifications`          | Create a notification            |

## ⏰ Scheduled Jobs

MediTrack uses `node-cron` to automatically generate notifications:

| Job                | Schedule       | Description                                         |
| ------------------ | -------------- | --------------------------------------------------- |
| Exam reminder      | Daily at 08:00 | Notifies users with appointments in the next 7 days |
| Overdue exam alert | Daily at 08:00 | Notifies users when a recommended exam is past due  |
| Calorie reminder   | Daily at 20:00 | Reminds users to log their daily nutrition          |
